AGENTDESK

Your work agents,
on your own Windows desk.

AgentDesk is a Windows desktop for work agents. Each bot has its own name, brand, personality, memory and conversation. It runs on your PC: it is not a cloud service and not an OpenAI product. Made by Castellon.CH in Biel/Bienne, Switzerland.

Read-only by default: writing files needs the separate “Write files” add-on, enabled explicitly.

Features

Several agents on one PC, each with its own identity, memory and sources, and the work kept on your own computer.

01

Bots with personality

Each bot has its own name, personality, colour and icon, and its own conversation.

02

Bots that consult each other

If you enable it, bots can consult one another.

03

Read sources

A file, a folder or a SharePoint library synced via OneDrive.

04

Read-only by default

Writing needs the separate “Write files” add-on, enabled explicitly.

05

Memory and history

Pinned memory and chat history for every bot.

06

Clone and export (Pro)

Clone a bot or export it. Light and dark themes.

How it works

Your files, folders or synced SharePoint→AgentDesk (on your PC, read-only by default)→Your chosen AI engine
1. UNZIP AND RUN

Nothing to install

A single portable file. No admin rights and no .NET install.

2. CREATE YOUR BOTS

Name, personality, sources

Give each bot its name, colour, icon and the files or folders it may read.

3. CHOOSE THE ENGINE

Your own AI account

Free: Codex with your own ChatGPT account. Pro: CLI engines, an OpenAI-compatible API engine and Microsoft Copilot Studio.

Your data

Where it lives
Bots, memory and chat historyOn the PC, next to AgentDesk.exe
API keysWindows Credential Manager
What leaves the PCOnly what you send to your chosen AI engine

AgentDesk is not a cloud service. The AI runs on your own account with the engine you choose.
